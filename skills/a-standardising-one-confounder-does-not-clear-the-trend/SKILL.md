# 교란 하나를 표준화했다고 추세가 설명된 건 아니다

## Problem

hots-replay-analysis P5-A(2026-11-03, PR #56). 단일 계정 PvP 314경기를 시간순 4분할했더니 캠프 유닛 마지막 타격 비율이 16.8% → 21.1% → 27.6% → 31.5%. 시간순 절반 차이 10.7%p, 무작위 절반 차이 중앙값 2.1%p — 우연이 아니다.

첫 가설: 영웅 구성 변화(9월 힐러 2경기 → 10월 48경기). 같은 영웅의 다른 사람 기준으로 간접 표준화하자 **기대값이 30.9/26.7/30.0/31.5%로 평탄**, O/E 0.54 → 1.00. 여기서 "영웅 구성으로 설명되지 않으니 본인 행동이 변했다"고 쓰기 직전이었다.

실제 원인: 4분할의 **게임 모드 구성**이 1분기 빠른 대전 78/0, 3분기 16/63(폭풍 리그). 모드별 값은 빠른 대전 19.3%, 폭풍 리그 32.5%. 같은 모드 안 시간순 절반 차이는 4~5%p로 줄었다. 남는 몫도 같은 모드 안의 시간 변화(파티·상대·패치)와 분리 불가.

## Rule

1. 기간 차이를 보고하기 전에, 각 시간 구간의 **모든 범주 축 구성표**(모드, 대기열, 역할, 승률, 플랫폼…)를 한 표로 찍는다. 구간별 승률도 — 결과와 묶인 지표는 승률 구성으로 움직인다.
2. 표준화는 축별로 따로가 아니라, 의심 축 안에서 시간 분할을 다시 본다("모드 안 시간순 절반").
3. 여러 지표 × 여러 분할에서 찾은 차이는, **모든 분할(시간 구간·범주)에서 같은 방향**일 때만 남기고 그것도 가설로 표기. 새 데이터로 재확인 계획을 적는다.
4. 짧은 코퍼스(수 주)에서는 "성향 변화"와 "구성 변화"를 분리할 수 없다고 명시하는 것이 결론이다.
