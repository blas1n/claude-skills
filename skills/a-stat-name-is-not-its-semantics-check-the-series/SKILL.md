# 통계 이름은 의미가 아니다 — 시계열로 재고, 동시 이벤트로 분류하라

## Problem

리플레이 `SScoreResultEvent`의 통계를 "경기 누계"로 노출하려 했다(hots PR #44).

- 증상 1: `DamageSoaked`는 이름상 받아낸 피해 누계인데, 같은 경기의 연속 점수 이벤트 사이에서 **9번 감소**했다(노바 11,921 → 11,002). 누계가 아니다.
- 증상 2: `TimeCCdEnemyHeroes`는 "초"로 보이지만 1,770초 경기에서 9,042 — 벽시계 초가 아니다.
- 증상 3: 이전 연구(PR #42)는 "종료 1,000루프 이내 = 종료 스냅숏"으로 나눠 333경기에 종료 340개(경기당 여러 개)를 셌다. **EndOfGame 통계와 같은 루프**로 나누자 종료는 정확히 경기당 1개, 나머지 68개는 전부 이탈 이벤트와 **같은 루프(0루프)** 였다.
- 흔한 오해: 이름과 문서 관례(점수 화면 = 누계, Time = 초)를 믿고, 분류는 "끝에 가까우면 끝"이라는 거리 직관을 쓴다.

## Solution

1. **연속 관측의 단조성**: 같은 대상(플레이어)의 시점 순 관측끼리 `b < a`를 센다. 0이 아닌 통계는 누계 목록에서 뺀다(또는 별도 표시).
2. **물리적 상한**: 시간 통계 ≤ 경기 길이, 비율 ≤ 1 등. 넘으면 단위를 확정하지 말고 원값 + `unit_status: unverified`.
3. **독립 대조**: 단위를 확정하려면 같은 원천이 아닌 데이터와 대조(예: TimeSpentDead vs 유닛 사망→부활 구간). 같은 게임의 다른 통계 이벤트와의 일치는 독립 근거가 아니다.
4. **분류는 동시 이벤트로**: 스냅숏 종류를 거리 임계값이 아니라 **같은 시점(loop)에 찍힌 원인 이벤트**(EndOfGame 통계, 이탈 이벤트)로 정한다. 어느 쪽에도 속하지 않는 것은 "미분류"로 남기고 값을 내지 않는다. "마지막 것 = 종료"로 승격하지 않는다.
5. 위 측정 각각을 실제 데이터 회귀 테스트로 고정한다(예: 감소 사례 하나를 원값으로 단언 → 왜 제외했는지가 테스트에 남음).

## Key Insights

- 존재율 100%·정수·중복 0 같은 형식 검사는 **의미**를 하나도 보증하지 않는다. 의미는 시계열과 상한에서만 드러난다.
- 거리 임계값 분류는 경계 근처 사건(종료 직전 이탈)을 섞는다. 같은 시점 공존은 0/1로 깔끔하게 갈렸다 — 원인 이벤트가 있으면 그걸 써라.
- 중간 스냅숏이 드물게라도 있으면 단조성 검사를 공짜로 할 수 있다. 그 데이터를 버리기 전에 먼저 써라.

## Red Flags

- 필드 이름만 보고 "누계", "초", "HP"라고 문서에 쓰려 할 때
- `end - loop > N`처럼 거리로 이벤트 종류를 나누는 코드
- "마지막 이벤트를 최종값으로" 쓰는 코드
- 한 경기에 '종료' 스냅숏이 여러 개로 세어질 때

## Case: 같은 키, 다른 저장 형식 — 그리고 교차검증 불일치는 검사기부터 의심 (hots PR #50)

- `TeamID`는 대부분의 전장 통계(`GhostShipCaptured`, `SoulEatersSpawned`, `DragonKnightActivated`, `HauntedMinesGolemsSpawned`)에서 **fixed 데이터**(4096배)인데, `SkyTempleCaptured`·`SkyTempleShotsFired`에서는 **int 데이터**이고, 중립(0)일 때는 **키 자체가 빠진다**.
- 독립 교차검증(같은 루프 사원 유닛 소유자 → 팀)이 19/39로 나왔고, 원인은 규칙이 아니라 검사기가 fixed만 읽은 것이었다. 규칙은 int → fixed 순으로 읽어서 맞았다.
- 대처: 키 이름으로 컨테이너를 가정하지 말고 "int 먼저, 없으면 fixed/스케일" 헬퍼 하나를 규칙과 검사기가 같이 쓴다. 기본값(0)일 때 키가 빠지는 경우(None)를 "중립"으로 명시한다. 교차검증이 반쯤 맞으면(≈50%) 규칙을 고치기 전에 원본 행 몇 개를 그대로 찍어 본다.
- 합성 테스트 픽스처도 실제 저장 형식으로 맞춘다. 틀린 형식(fixed)으로 만든 픽스처는 두 형식을 다 읽는 코드에서 초록이라 형식 차이를 숨긴다.
