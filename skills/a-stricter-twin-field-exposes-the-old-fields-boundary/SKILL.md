# 엄격한 쌍둥이 필드는 기존 필드의 경계 위반을 드러낸다

## Problem (2026-10-22, hots-replay-analysis PR #27)

`intent.initial`(판단 시점 의도)을 추가하며 처음엔 기존 `provisional` 분류를 그대로 썼다. 1차 AI 재라벨에서
"initial이 판단 시점이라면서 목적지는 판단 후 11초까지 이어진 클릭 묶음 중심"이라는 누출 지적이 나왔다.
initial을 판단 시점 클릭 하나로 바꾸자, 2차에서 누출 지적이 오히려 늘었다(B 8→17) — 이번엔
**기존 provisional·대안이 판단 이후 클릭을 쓰고 있다**는 지적. 실측: 774건 중 91건(12%)은 클릭 하나로
읽으면 종류가 다르고, 115건은 묶음이 5초 넘게 이어졌다. 이전 4개 PR 동안 아무도 못 봤던 것은 비교 대상이 없었기 때문.

## Rules

1. as-of 필드를 추가하기 전에 기존 필드의 입력 시각 분포(최대·p90, 기준 시각 이후 비율)를 측정한다.
2. 차이가 나는 항목은 플래그(`revised`)로 표면화하고 하류 판단(부정 판정 등)을 막는다 — 기존 필드를 고치면 대량 변경이 되면 다음 작업으로 분리.
3. 리뷰의 누출 지적이 늘면 "새로 만든 누출 / 드러난 기존 누출 / 이전부터 있던 노출"로 분류해서 보고한다. 숫자만 보면 퇴보로 읽힌다.

## Key Insights

- "판단 시점" 정의는 실제로 쓴 입력의 최대 시각으로 검증해야 한다. 이름(provisional, decision-time)은 아무것도 보장하지 않는다.
- 같은 도메인 함정: 강한 증거처럼 보이는 신호(적 영웅 공격 명령)가 어디서나 발생하면 목적 판별력이 없다 — 대체가 아니라 경쟁 가설로만.
