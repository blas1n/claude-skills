# 기준점에서 재는 규칙은 기준점의 오류를 물려받는다

## Problem (2026-10-26, hots-replay-analysis PR #35)

continuation 오탐(p32·p33·p63)은 "변화 뒤 바깥으로 이어진 이동 묶음 → 자리에서 떨어진 곳에서 교전 재개"였다.
규칙 H1s(3클릭 이상 연속으로 자리에서 멀어짐 ≥10, 재개 거리 ≥10, 지원 중 제외)는 개발 241건에서
오탐 A 5·B 7 제거 / 의미 손실 A 1·B 2 로 좋아 보였다. 독립 holdout 57건에서는:
- 선별성은 진짜였다: 내린 사례 오탐 비율 57%/36% vs 남은 후보 7%/10%.
- 그러나 의미 있는 판단 유지율 84%/79% (사전 등록 90% 미달) → 되돌림.
- 잃은 판단 5건 중 4건의 원인은 규칙이 아니라 **기준점**: 자리(prior place)가 변화 5~7초 전 묶음이라
  대상이 이미 옮겨 간 뒤였고(교전 쪽으로 들어가는 이동이 "멀어짐"으로 읽힘), 재개 거리를 모든 사후 명령
  중심으로 재서 늦은 명령 하나가 끌어냄. 나머지 1건은 데이터 결함(영웅 대상 명령의 분류 누락 2.6%)이
  공백을 인위로 늘림.
- 개발에서 이미 경고가 있었다: 임계값 10→12.5 에 보류가 14→4건으로 절벽.

## Rules

1. 거리/방향 규칙을 얹기 전에 **기준점 자체의 정확도를 따로 감사**하라. "기준점이 판단 시점의 실제 위치를
   대표하지 못하는 사례"를 세지 않으면, 새 규칙의 holdout 손실은 그 사례 수만큼 나온다. 기준점 수정이
   규칙 추가보다 먼저다.
2. 기준점이 들어가는 측정은 **가장 이른 증거**로 재라(첫 재개 명령의 거리). 전체 중심은 늦은 이상치에 끌린다.
3. 개발에서 임계값을 한 칸 움직여 결과가 크게 변하면, 그 규칙은 과적합 후보로 사전 등록 문서에 적어 두고
   holdout 실패를 예상하라.
4. "판단을 덜 만드는 것인가"에 답하려면 사전 등록에 두 기준을 **둘 다** 둬라: 선별성(내린 집합의 오탐
   비율 ≥ 2× 남은 집합) 과 유지율(기준 의미 있는 판단 중 남은 비율 ≥ 90%). 선별성만 통과해도 채택 근거가 아니다.
5. 경쟁 가설은 오프라인 정의(연구 스크립트)로 같은 holdout 에서 함께 채점하되, holdout 을 본 뒤 다른 가설로
   갈아타지 않는다(새 holdout 필요). 구현과 오프라인 정의가 같은 집합을 고르는지 개발 사례에서 먼저 확인하라
   (창 경계 하나 — 변화 시각 정각의 명령 포함 여부 — 로 1건이 갈렸다).
6. 검토자 노트의 "기계가 이 명령을 세지 않았다" 지적은 데이터 결함 신호다. 전 코퍼스에서 즉시 세라.
