# 클라이언트가 걸러 기록한 입력 로그는 숨은 상태를 담고 있다

hots-replay-analysis 2026-10-21 (Heroes of the Storm 리플레이, 아나 스킬 복원)에서 얻은 교훈.

## 상황

- 리플레이에는 스킬 *입력*만 있고 실행·적중은 없다. "입력 ≠ 실행"이라 스킬 복원은 불가능해 보였다.

## 발견

1. **입력 간격 분포에 빈 구간이 있었다.**
   - 수면총(쿨다운 14초): 간격 775개 중 0.25초 이하 166개, 0.25~8초 9개, 나머지는 쿨다운 경계 이상.
   - 사람은 쿨다운 중에도 키를 누른다. 기록된 간격이 경계에서 잘린다는 것은 **클라이언트가 준비 안 된 능력의 명령을 보내지 않는다**는 뜻이다.
   - 0.25초 이하 묶음은 시전 시간(CastIntro 0.25초) 안의 재입력이다.
2. **전제를 검증한 방법**: 쿨다운을 줄이는 특성(슬럼버 셸 −2초)을 고른 경기에서 하한이 정확히 12.3초로 움직였다. 경계가 상태 변화를 따라가면, 그 경계는 사람 습관이 아니라 상태가 만든 것이다.
3. **결과 라벨로 전환**: 게임 데이터에 "수류탄이 적 유닛을 하나도 못 맞히면 쿨다운 −3초" 환급 규칙이 있었다.
   - 다음 입력까지의 간격은 이번 시도의 실제 쿨다운의 상한이다(미실행이면 쿨다운 0).
   - 간격 < 16초 → 적 미적중(또는 미실행)
   - 16초에 준비되자마자 재입력 → 실행 + 적 적중
   - 이 라벨로 위치 기반 적중 판정을 검증했다. 미적중 11건에서 위양성 0이었다.

## 방법

1. 같은 동작의 연속 입력 간격을 아주 촘촘한 구간(1틱 단위)으로 히스토그램한다.
2. 빈 구간의 하한이 설정값(쿨다운·한도)과 맞는지 본다.
3. 설정값이 바뀌는 하위 집단(특성·플랜·버전)에서 하한이 같이 움직이는지 본다. 움직이지 않으면 전제를 버린다.
4. 결과에 따라 상태를 바꾸는 규칙(환급, 페널티, 재시도 지연)을 데이터·코드에서 찾는다.
5. "간격 ≥ 실제 상태값"이라는 *상한* 논리만 쓴다. 플레이어가 늦게 누르면 정보가 없다(판정 불가). "준비되자마자 재입력"한 경우만 양쪽 라벨이 붙는다.
6. 묶음(시전 시간 안의 재입력)은 하나의 시도로 합친다.

## 주의

- 라벨이 붙는 비율이 낮다(이번에 623건 중 40건). 편향된 표본(즉시 재입력하는 상황)일 수 있다.
- 규칙이 세는 대상을 확인하라. 이 경우 "적 유닛"은 미니언을 포함해서 "적 *영웅* 적중"과는 다르다.
- 전제는 Strongly supported일 뿐 엔진 사실이 아니다. 화면이나 엔진 계측으로 한 번은 직접 확인할 계획을 남겨라.
