# 바뀌지 않은 항목의 재라벨 변동이 잡음 바닥이다

## Problem (2026-10-22, hots-replay-analysis PR #27)

선택 의도 복원 후 고정 평가셋 56건을 같은 세션·같은 질문·같은 모델(A=Opus, B=Sonnet)로 변경 전/후 블라인드 재라벨.
전체: correct A 32→36, B 27→31 — 개선처럼 보였다. 그런데 **표시 선택이 그대로인 48건**에서도 라벨이
A +6/−5, B +8/−3(각 ±11) 바뀌었다. 전체 +4는 이 변동과 구분되지 않았다. 신호는 출력이 실제로 바뀐 4건
(A 4/4 개선, B 2 개선·2 동일, 악화 0)뿐 — 표본이 작아 "악화 없음" 정도만 말할 수 있었다.
추가로 새 패킷에는 새 필드(intent)가 있어 버전 블라인드가 원천적으로 불가능했다.

## Rules

1. 재라벨 집계 전에 항목을 **출력 변경 / 표시만 변경 / 불변** 그룹으로 나눈다(키는 버전 간 출력 diff).
2. 불변 그룹의 개선·악화 수 = 잡음 바닥. 전체 증가분이 이보다 작거나 비슷하면 "개선"이라 쓰지 않는다.
3. 변경 그룹은 "악화 0 / n" 같은 방향성으로만 보고하고 n을 같이 적는다.
4. 변경 전 라벨도 **같은 세션에서 다시** 받는다(이전 PR 라벨과 섞으면 세션 간 변동이 더해진다 — 여기서도 PR 이전 라벨과 같은 세션 재라벨이 달랐다).
5. 새 필드가 버전을 드러내면 블라인드라고 쓰지 말고 "버전 표시만 제거"라고 쓴다.
6. 외부 고정 기준(구현 전 커밋한 reference)과의 기계 비교를 병행한다 — 검토자 변동이 없다.

## Key Insights

- AI 검토자의 run-to-run 변동은 작은 평가셋에서 개선 폭과 같은 크기다. 이걸 재지 않으면 잡음을 성과로 보고한다.
- 그 시점이 "AI 라벨만으로는 더 판정할 수 없다 → 사람 라벨 필요"를 말할 근거가 된다.
